# Kinetic Routine

A minimalist twice-weekly compound strength training companion. Built with the Anthropic beige & terracotta design language.

## What It Does

**Page 1 — Setup**: Pick your training day (A or B), progression phase (1–3), and rest interval. The app auto-detects Tuesdays (Day A) and Saturdays (Day B).

**Page 2 — Workout**: Full-screen exercise flow with hand-illustrated visuals, rotating form cues, tap-to-complete set tracking, and a circular rest timer with audio chime.

## The Program

| | Day A (Tuesday) | Day B (Saturday) |
|---|---|---|
| **Focus** | Knee Dominance, Horizontal Push/Pull | Hip Dominance, Vertical Push/Pull |
| **Exercises** | Squats → Bench → Rows → RDLs → Core | Deadlifts → OHP → Pull-Ups → Lunges → Core |

### Three Phases
- **Phase 1** (Wk 1–4): Foundation — DB/BW variations, 3×8–10, RPE 6–7
- **Phase 2** (Wk 5–8): Overload — Barbell compounds, 3×6–8, RPE 7–8  
- **Phase 3** (Wk 9–12): Strength — Heavy loads, 4×4–6, RPE 8–9

## Stack

React · TypeScript · Vite · Tailwind CSS · Lucide Icons · Web Audio API
